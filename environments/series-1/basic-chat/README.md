# Series 1: Basic Microsoft Foundry Chat

This is the only environment included in Series 1. It will reproduce the basic Microsoft Foundry chat proof of concept with Terraform, following the upstream Azure Architecture Center implementation. The environment covers the Foundry account and project, model deployment, Bing grounding connection, monitoring, and App Service chat front end. The prompt agent is created in the Foundry portal as directed by the walkthrough.

Terraform implementation files will be added to this root module as the environment is implemented. Its reusable module boundaries are listed in the [module catalogue](../../../modules/README.md).
